# Sonu Kumar — Freelance Data Analyst Portfolio

A responsive static portfolio focused specifically on freelance Data Analytics services.

## Included
- `index.html`
- `styles.css`
- `script.js`

## Customize before publishing
1. Replace `your-email@example.com` in `index.html` with your real email.
2. Replace the LinkedIn placeholder URL with your profile URL.
3. Update individual GitHub project URLs if you have separate repositories.
4. Open `index.html` locally to preview.

## Publish with GitHub Pages
Create a repository such as `freelance-portfolio`, upload these three files, then enable GitHub Pages from the repository settings.
